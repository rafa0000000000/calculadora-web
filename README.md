Justificativa da escolha: JavaScript puro

- O projeto é pequeno, com uma tela só e poucas funções, então o JavaScript puro resolve sem precisar de framework.
- Escrevendo tudo em JavaScript puro, deu para entender como o visor é atualizado, como os números e operadores são guardados e como a conta é feita.
- O projeto tem só três arquivos (index.html, style.css e script.js), sem instalar nada. Basta abrir o index.html no navegador.
- Usei o que foi visto nas aulas: variáveis, funções, if, eventos e manipulação do DOM.
- Sem bibliotecas externas, a calculadora funciona em qualquer navegador e também no GitHub Pages.
- O Vue.js seria melhor em um projeto maior, com várias telas ou muitos dados mudando ao mesmo tempo. Para uma calculadora simples, deixaria o projeto mais complicado sem ganho real.
